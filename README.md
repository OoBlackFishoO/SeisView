# SeisView

[English](README.en.md) | 中文

SeisView 是一款面向地震数据的桌面可视化与转换工具，提供三维数据体、二维剖面与单道波形的联动浏览、多数据对比，以及论文用图和数据文件导出。

![SeisView 主界面](assets/主界面v0.4.0.png)

![载入示例后的界面](assets/载入示例后的界面v0.4.0.png)

---

## 功能概览

- **数据载入**：支持 `.npy`、`.npz`、`.mat`、`.sgy` / `.segy`、`.su`，可拖放导入，也可从命令行直接打开文件。
- **联动浏览**：三维数据体、共炮点剖面、共检波点剖面、时间切片与单道波形联动；在三维体上选择面、在剖面上选择道，切片位置与目标道号在各视图间保持一致。
- **多数据对比**：最多同时载入 3 份同形状数据并排显示，可同步切换切面与目标道；各面板共用同一色标窗口，叠加波形与单道曲线按数据顺序配色。
- **显示调节**：提供密度图与仅 wiggle 曲线两种显示方式，以及色标口径、对比度、AGC、渲染抽稀等参数；当前设置不适用的控件会自动禁用。
- **扫掠浏览**：通过播放头或播放功能连续切换切片，便于观察同相轴的横向连续性。
- **工作区布局**：提供单视图与分屏模式及多种预设构图；面板可拖动换序、拉出为独立窗口或拖回主窗口。
- **导出与转换**：支持整卷数据、逐剖面数据、剖面图、wiggle 剖面图和波形图导出；图片可输出为带物理坐标单位的 PNG / SVG；wiggle 剖面与波形图支持曲线线型与图例开关。

## 适用场景

- 检查地震数据的维度、轴序、振幅范围与有效道分布。
- 对比处理前 / 后的数据、不同处理结果或不同显示参数。
- 进行数据质控，例如定位缺道、坏道和异常振幅。
- 为报告、论文或汇报制作统一的剖面图和波形图。

## 快速开始

### Windows 安装包

从 [Releases](https://github.com/OoBlackFishoO/SeisView/releases) 下载 `SeisView-*-win64.zip`，解压整个文件夹后双击 `SeisView.exe`。无需安装 Python。

> 发布包为文件夹模式，需保留完整目录，不能只复制 exe。

### 从源码运行

```bash
pip install -r requirements.txt
python main.py
```

也可以直接打开指定文件：

```bash
python main.py D:\data\volume.npz
```

启动后可点击「载入示例」查看内置合成数据；执行 `python make_sample.py` 可生成额外的示例文件。

## 支持的数据格式

| 格式 | 说明 |
| --- | --- |
| `.npy` | NumPy 裸数组 |
| `.npz` | NumPy 多变量容器，可选择变量 |
| `.mat` | MATLAB v4 / v5 / v7；不支持 v7.3（HDF5） |
| `.sgy` / `.segy` | 标准 SEG-Y |
| `.su` | Seismic Unix，无文件头 |

首次打开 `.npy` / `.npz` / `.mat` 时，软件会要求确认各维的物理含义（炮点、检波器、时间），并按文件记住该设置。

![首次打开文件时确认维度轴](assets/设置维度轴.png)

### SEG-Y / SU 数据说明

- 炮点、检波器与时间三个维度分别取自 `FieldRecord`、炮内 `TraceNumber` 顺序与样点。
- 当炮点与检波点位置不一致时，检波器轴表示炮内道序，时间切片表示炮号与道号的索引平面。
- 缺道按道号定位，缺失位置留空，并在载入摘要中说明。
- 大文件按需读取，打开文件时不会将完整数据载入内存。

## 界面与操作

| 区域 | 操作 |
| --- | --- |
| 顶栏 | 打开文件、载入示例、导出 / 转换 |
| 左侧设置 | 选择变量、设置采样间隔与道间距、切换切片方向、调节显示参数和对比数据 |
| 三维面板 | 拖动旋转、滚轮缩放；点击某个面切换到对应剖面 |
| 剖面面板 | 左键拖动平移、滚轮缩放、双击复位；点击切换目标道 |
| 波形面板 | 显示当前道的单道记录；对比模式下叠加多份数据 |
| 面板标题行 | 拖动调整位置或拉出独立窗口；剖面组标题移动整组，组内 `⇄` 仅交换数据顺序 |

## 导出与转换

顶栏「导出 / 转换」（快捷键 `Ctrl+E`）提供以下内容：

| 导出内容 | 支持格式 | 说明 |
| --- | --- | --- |
| 整卷数据 | `.npy` / `.npz` / `.mat` / SEG-Y / SU | 导出全部采样，形状为炮点 × 检波器 × 时间 |
| 逐剖面 | `.npy` / `.npz` / `.mat` | 沿一个方向切片，每片写成一个独立文件；支持片层范围 |
| 剖面图 | PNG / SVG | 白底、四边坐标轴、带色标的密度图 |
| wiggle 剖面 | PNG / SVG | 纯 wiggle 曲线图；对比模式下叠加全部数据源 |
| 波形图 | PNG / SVG | 当前单道波形；对比模式下包含多份数据 |

矩阵导出仅包含数据本身，不写入采样间隔等元信息；缺道位置以 0 填充。图片使用当前剖面或单道的全分辨率数据重新绘制（不受屏幕抽稀影响），并沿用屏幕当前的色标、对比度与 AGC 设置；不包含界面主题和窗口装饰。

### 论文用图设置

图片导出提供以下设置：

- 物理尺寸（mm）与分辨率（DPI），默认 180 × 130 mm、300 DPI。
- 字体、字号（默认 14 pt）与线宽（默认 1 pt，可按 0.1 pt 调整）。
- 四边坐标轴；刻度线可朝内或朝外；只显示主刻度；刻度数字与轴标题可分别放在上 / 下、左 / 右。
- 横轴与纵轴可分别指定主刻度间隔：时间轴为 s，距离轴为 m，波形图纵轴为振幅；`0` 表示自动；可强制在轴两端显示刻度数字。
- 图注支持中文 / 英文切换；轴标题可自定义或留空隐藏；标题留空时不添加标题。
- 色标可放在右侧或底部，可关闭色标文字；支持透明背景。
- 共炮点剖面的横轴可显示检波器位置或偏移距。
- wiggle 剖面与波形图可分别设置各数据源的曲线颜色与线型，并可显示或隐藏图例。
- 波形图可指定导出的时间范围，按 0.1 s 调节。
- 导出预览支持滚轮缩放和拖拽平移。

## 构建 Windows 程序

运行 `build.bat`，产物位于：

```text
dist\SeisView\SeisView.exe
```

## 环境要求

- Python 3.10+
- PySide6、pyqtgraph、PyOpenGL、numpy、scipy、segyio
- 三维视图需要 OpenGL 4.x；不可用时会自动降级，剖面与波形仍可正常使用

## 更新记录

### v0.4.0

- **论文用图导出**：新增四边坐标轴、刻度线朝内 / 朝外、刻度数字与轴标题换边、图注中英文切换、轴标题自定义或隐藏、标题可选、色标位置与文字开关、透明背景；色标可放右侧或底部，底部色标保持剖面绘图区比例；共炮点剖面横轴支持偏移距；新增独立的 wiggle 剖面导出；wiggle 剖面与波形图可设置曲线颜色、线型，并可显示或隐藏图例。
- **出图参数**：支持按物理尺寸与 DPI 输出；默认字号 14 pt、线宽 1 pt，线宽可按 0.1 pt 微调；横轴与纵轴可分别设置主刻度间隔，并可强制显示轴两端刻度；刻度数字与刻度线间距加大，端点刻度完整显示；波形图导出时间段按 0.1 s 调节；导出预览支持缩放与平移。
- **色标**：自动口径以 P99 为兜底，并提供 P95 / P98 / P99 / 手动选项；导出图片与屏幕显示使用同一套色标、对比度与 AGC 设置。
- **导出流程**：设置窗口内容区支持滚动；默认导出文件名不会与当前数据源文件重名，并保护当前数据源文件不被误覆盖；文件名后缀与所选格式不一致时阻止导出；多张剖面图导出可取消，已写出的文件保留。
- **稳定性**：NaN / Inf 不再影响色标、波形峰值与导出坐标范围；空维度数据拒绝载入；损坏的 `.npy` / `.npz` / `.mat` 文件给出明确提示；对比模式下替换数据要求形状一致，添加对比失败时恢复原数据源面板。
- **大文件与缓存**：重复打开较大的 `.mat` 与 SEG-Y / SU 文件时会复用已读取的数据，清空数据后自动释放内存；打开、扫描和读取大文件时显示等待光标与状态提示。
- **交互**：拖动剖面绿线时同步更新三维对应切片（时间切片保持不动）；侧边栏一键收放改为任一设置展开时全部收起。
- **界面**：界面冗余文案清理：移除重复说明与多余提示，设置区与导出对话框更紧凑。
- **修复**：修复发布版 PNG / SVG 导出缺少组件的问题；修复导出图边缘刻度数字被图幅裁切或与刻度线错位的问题。
- **依赖**：`pyqtgraph ≥ 0.14`、`segyio ≥ 1.9.14`。
